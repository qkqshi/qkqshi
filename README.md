<h3>About / ОБО МНЕ</h3>
<p>I build practical products with AI — from Telegram apps to content tools and business automation.</p>
<p>Создаю полезные продукты с AI: Telegram-приложения, инструменты для контента и автоматизацию бизнеса.</p>
<h3>Selected work / ИЗБРАННЫЕ ПРОЕКТЫ</h3>
<h4><a href="https://github.com/qkqshi/lesson-flow">01 / lesson-flow</a></h4>
<p>A teacher’s Telegram Mini App with Google Calendar sync, lesson editing, student tracking and income planning.<br>Telegram Mini App преподавателя: синхронизация с Google Calendar, управление уроками, список учеников и планирование дохода.</p>
<p><strong>Stack:</strong> Next.js / TypeScript / PostgreSQL</p>
<h4><a href="https://github.com/qkqshi/ai_content_maker">02 / ai_content_maker</a></h4>
<p>A Telegram bot for photo-to-video generation, talking avatars and storyboard Reels. Uses Kling, Hedra, ElevenLabs, FFmpeg and PostgreSQL.<br>Telegram-бот для видео из фото, говорящих аватаров и Reels с раскадровкой. Использует Kling, Hedra, ElevenLabs, FFmpeg и PostgreSQL.</p>
<p><strong>Stack:</strong> Python / FFmpeg / PostgreSQL</p>
<h4><a href="https://github.com/qkqshi/ai_tender_bot">03 / ai_tender_bot</a></h4>
<p>Find and filter B2B-Center tenders by keywords, participants and deadlines, then receive matching results in Telegram. Includes Playwright fallback.<br>Поиск закупок B2B-Center по ключевым словам, числу участников и дедлайнам. Подходящие результаты отправляются в Telegram; предусмотрен Playwright fallback.</p>
<p><strong>Stack:</strong> Python / Playwright / Telegram</p>
<h4><a href="https://github.com/qkqshi/smetchikbot">04 / smetchikbot</a></h4>
<p>Generate furniture quotations from Word documents, calculate costs and export PDF, PowerPoint and Excel files through Telegram.<br>Коммерческие предложения по мебели из Word: расчёт стоимости и экспорт в PDF, PowerPoint и Excel через Telegram.</p>
<p><strong>Stack:</strong> Python / DOCX / PDF / PPTX / XLSX</p>
<h3>Stack</h3>
<p>Python, TypeScript, Next.js, React, PostgreSQL, Telegram, aiogram, Docker, Playwright.<br>AI tools: Claude Code, Antigravity.</p>
